# Hard-Standalone Package-Owned Skills Remediation Plan

Goal: Starting from the exact frozen 157-test v0.1.0 release, remove runtime dependence on external process skills and replace it with package-owned document-specific planning, execution, debugging, recovery, and verification modules without weakening exhaustive anti-skimming traversal.

Baseline: `/mnt/data/recovered-freeze/chunking-document-workflows-0.1.0.zip`

Design: `design/2026-09-08-hard-standalone-package-owned-skills.md`

## Global constraints

- Preserve canonical root `SKILL.md`.
- Frozen v0.1.0 is immutable recovery authority; work in a new tree.
- Chunking is mechanism; exhaustive traversal is product.
- Do not copy external skill prose verbatim.
- External process frameworks may inform development only.
- Normal runtime must not require Superpowers or another external process plugin.
- Preserve bundled extractors and forged-manifest defense.
- Preserve source/distribution vs installed runtime vs per-run evidence separation.
- Tests first for every behavior change.
- No completion claim until frozen extracted bytes pass the final gate.
